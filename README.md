# KAROSA — сайт автосервиса с записью и расчётом стоимости

Next.js 15 (App Router) · TypeScript · Tailwind · Framer Motion · MongoDB.
Mobile-first: мобильная версия — основной сценарий, десктоп — расширение.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Без `MONGODB_URI` проект работает на данных в памяти — демо клиенту можно
показать сразу, но записи живут до перезапуска.

---

## Три независимых слоя

Дизайн, контент и логика не пересекаются. Под клиента меняется только нужный.

| Что меняем | Где | Компоненты трогаем? |
|---|---|---|
| Стиль целиком | `src/config/theme.ts` — одно слово | нет |
| Цвета, радиусы, тени, отступы | `src/app/globals.css` | нет |
| Тексты, контакты, часы | `src/config/site.ts` | нет |
| Работы, цены, длительность | `src/config/catalog.ts` | нет |
| Классы машин и коэффициенты | `src/config/vehicle.ts` | нет |
| Отзывы, FAQ, галерея | `src/config/content.ts` | нет |
| Состав и порядок блоков | `src/config/blocks.ts` | нет |
| График, шаг слотов, механики | `src/config/schedule.ts` или `/admin` | нет |

## Три стиля

`src/config/theme.ts`:

```ts
export const THEME: ThemeName = "garage";  // garage | precision | asphalt
```

| Стиль | Характер |
|---|---|
| `garage` | Тёмный цех: графит, янтарный акцент, капслок в заголовках, диагональная разметка на фоне. Радиус 8px, резкие анимации |
| `precision` | Светлый инженерный: белое и синее, миллиметровка, линия слева у заголовков. Радиус 6px |
| `asphalt` | Тёплый нейтральный: бетон и охра, мягкие формы. Радиус 22px, плавное движение |

Показать клиенту без пересборки: `?theme=precision` в адресе.

## Расчёт стоимости

Главная особенность домена: **цена зависит от класса машины**. Замена масла
на Fabia и на Touareg отличается объёмом масла и временем на подъёмнике.

`src/config/vehicle.ts` задаёт классы и множители:

| Класс | Множитель | Примеры |
|---|---|---|
| Малый | 0.85 | Fabia, Polo, Yaris |
| Средний | 1.0 | Octavia, Golf, Focus |
| Кроссовер | 1.25 | Kodiaq, Tiguan, RAV4 |
| Внедорожник, минивэн | 1.5 | Touareg, X5, Transporter |

Множитель применяется **и к цене, и к длительности**. Второе принципиально:
если растянуть только цену, расписание поедет на второй же записи за день.

Работы с `flatRate: true` (компьютерная диагностика) множитель игнорируют —
сканер работает одинаково на любой машине.

Расчёт живёт в `src/lib/pricing.ts` и используется одновременно калькулятором,
формой записи и сервером. Расхождение цифр между ними убило бы доверие к обоим.

Цены округляются до полусотни: `1 487 Kč` выглядит как результат машинного
умножения и подрывает доверие сильнее, чем честное «около 1 500».

**Класс проверяется на сервере по справочнику**, а не берётся из запроса:
иначе достаточно прислать свой множитель, чтобы насчитать себе скидку.

## Карта блоков

Порядок задаётся массивом `pageBlocks` в `src/config/blocks.ts`.

| # | Блок | Файл | Задача |
|---|---|---|---|
| 1 | Hero | `blocks/Hero.tsx` | Кто мы + начать запись без скролла |
| 2 | About | `blocks/About.tsx` | Доверие: текст и три факта |
| 3 | Services | `blocks/Services.tsx` | Прайс, вход в запись |
| 4 | **Calculator** | `blocks/Calculator.tsx` | Расчёт стоимости — снимает главный барьер |
| 5 | Booking | `blocks/Booking.tsx` | Запись |
| 6 | Reviews | `blocks/Reviews.tsx` | Отзывы, лента scroll-snap |
| 7 | Gallery | `blocks/Gallery.tsx` | Работы из цеха |
| 8 | FAQ | `blocks/Faq.tsx` | Снять возражения |
| 9 | Footer | `blocks/Footer.tsx` | Контакты, часы |

Калькулятор стоит **перед** записью намеренно: сначала отвечаем на вопрос
«сколько это будет стоить», потом зовём записаться.

## Запись

```
features/booking/
  BookingProvider.tsx      состояние: машина, работы, шаг, статус
  AvailabilityProvider.tsx график и занятость с сервера
  BookingFlow.tsx          оркестратор шагов
  BookingSheet.tsx         шторка
  steps/
    StepService.tsx        1. класс машины + работы
    StepWhen.tsx           2. механик, дата, время
    StepContact.tsx        3. модель, номер, телефон, фото
    StepDone.tsx           4. подтверждение
```

Класс машины спрашивается **до** выбора работ. Иначе человек видит цену за
седан, выбирает кроссовер и наблюдает, как цифры растут на четверть.

Слоты считаются от суммарной длительности всех работ с учётом класса.
Логика — `src/lib/slots.ts`, чистая функция от графика и занятости.

## Админка

`/admin`, пароль в `ADMIN_PASSWORD`. Три вкладки: **График** (часы по дням,
разовые выходные, шаг сетки), **Механики** (работы, личные выходные, приём
вкл/выкл), **Записи** (список с телефоном, машиной, подтверждением и отменой).

Сессия 12 часов, состояние на сервере не хранится — токен подписан HMAC.

## Уведомления

```
services/notifications/
  telegram.ts  реальная реализация
  stubs.ts     заглушки email / whatsapp / sms
  index.ts     реестр каналов
```

Каналы включаются переменной `NOTIFY_CHANNELS`. Без ключей канал работает
в dry-run: пишет в консоль вместо отправки.

В Telegram уходит машина, класс, список работ, расчёт с пометкой
«без запчастей» и время окончания.

## Что специально сделано для мобильной версии

- `100dvh` вместо `vh` — адресная строка Safari не срезает низ
- `env(safe-area-inset-bottom)` — контент не уезжает под полосу жестов iPhone
- `font-size: 16px` у полей — Safari не зумит при фокусе
- `type="tel"` + `inputMode` — цифровая клавиатура сразу
- всё интерактивное ≥ 44–48px
- дата выбирается лентой дней, а не нативным календарём ОС
- кнопка действия закреплена внизу шторки
- шторка закрывается свайпом, `overscroll-contain` держит страницу
- ленты на нативном `scroll-snap`, без JS-слайдера
- `prefers-reduced-motion` отключает анимации
